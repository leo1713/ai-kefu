## 2. 知识库管理

路径：**知识库**

知识库是 AI 回答问题的文档来源。上传后，AI 会在回答时自动检索相关内容。

### 创建知识库集合

1. 点击「新建集合」，填写名称（如"退款政策"、"产品说明"）
2. 点击确认创建

### 上传文档

1. 选择已创建的集合
2. 点击「上传文档」，支持 PDF、TXT、MD 格式
3. 上传后系统自动分片和向量化，状态变为「已处理」后即可使用

### 注意事项

- 一个集合可以包含多个文档
- 文档内容越具体，AI 回答越准确（避免上传无关内容）
- 删除文档后，AI 不再引用该内容

## 3. QA 知识库

路径：**QA 知识库**

QA 知识库用于精确问答对。当用户问题与 QA 条目匹配时，系统将标准答案优先注入给 AI，确保回答准确一致。

**与知识库的区别：**
- 知识库：适合长文档，AI 自由检索
- QA 知识库：适合标准化问答，如退款天数、营业时间、常见政策

### 手动添加 QA 条目

1. 点击「添加 QA」
2. 填写问题（如"你们多久退款？"）和答案（如"退款申请审核通过后 3-5 个工作日到账"）
3. 点击保存

### 批量导入

1. 准备 JSON 文件，格式如下：
   ```json
   [
     {"question": "怎么申请退款？", "answer": "在订单详情页点击「申请退款」，填写原因后提交。"},
     {"question": "退款多久到账？", "answer": "审核通过后 3-5 个工作日到账。"}
   ]
   ```
2. 点击「批量导入」，上传 JSON 文件

### 编辑和删除

- 点击条目右侧「编辑」可修改问题或答案
- 点击「删除」移除该条目

## 4. Agent 配置

路径：**Agent 管理**

Agent 是 AI 客服的核心配置，决定 AI 的角色、回答风格和能力。

### 主要配置项

| 配置项 | 说明 |
|--------|------|
| 名称 | Agent 的标识名称 |
| 系统提示词 | 决定 AI 的角色和行为（最重要的配置） |
| 模型 | 使用的 AI 模型（默认 claude-sonnet-4） |
| 温度 | 回答创意度，0-1，客服建议 0.3 |
| 最大 Token | 单次回答最大长度，建议 2000 |
| 知识库 | 绑定哪些知识库集合 |

### 修改系统提示词

系统提示词直接影响 AI 的回答风格。示例：

```
你是「XX电商」的专业客服，负责解答客户的售后和咨询问题。
- 回答简洁友好，不超过 200 字
- 遇到退款问题，先核实订单信息
- 无法解决的问题，主动提出转接人工客服
```

修改后点击保存，下次对话立即生效。

### 专业 Agent（多 Agent 路由）

系统内置退款 Agent 和物流 Agent：
- 用户询问退款相关 → 主 Agent 自动路由到退款 Agent
- 用户询问物流相关 → 主 Agent 自动路由到物流 Agent

## 5. 工作流配置

路径：**工作流**

工作流用于处理固定流程的场景，如"查询订单 → 判断状态 → 回复用户"。

### 创建工作流

1. 点击「新建工作流」，填写名称
2. 填写**触发关键词**（如"查订单、订单状态、查快递"），多个关键词用逗号分隔
3. 添加节点：

| 节点类型 | 用途 |
|----------|------|
| 发消息 | 发送固定文本或 AI 生成的消息 |
| 条件判断 | 根据变量值走不同分支 |
| 调工具 | 调用订单/支付/物流查询 |
| 结束 | 工作流结束 |

4. 点击保存并启用

### 触发优先级

用户发消息时，系统按以下顺序处理：
1. 工作流关键词匹配（最高优先级）
2. QA 精确匹配
3. 知识库 RAG 检索
4. Agent 直接回复

### 启用和停用

- 工作流列表中可随时切换启用/停用状态
- 停用后关键词不再触发该工作流

## 6. 客服管理

路径：**客服管理**

### 添加客服

1. 点击「添加客服」
2. 填写姓名、用户名、密码
3. 客服账号用于登录客服工作台

### 启用和停用

- 停用的客服无法登录工作台
- 已分配给停用客服的会话需要重新分配

## 7. 客服工作台

路径：**客服工作台**

客服工作台是人工接管会话的操作界面。

### 登录

工作台有独立的登录，使用客服账号（非管理员账号）登录。

### 界面说明

- **左侧**：会话列表，实时显示新转入的会话，连接状态圆点（绿=已连接）
- **右侧上方**：当前会话的消息时间线
- **右侧下方**：消息输入框

### 接管会话

当 AI 触发转人工时，会话出现在左侧列表，点击即可接管。

### 回复消息

1. 在右侧输入框输入回复内容
2. 点击「发送」或按 Enter
3. 消息会同步发送到用户的企业微信

### 关闭会话

处理完成后，在对话记录页点击「关闭」，会话标记为已完成。

## 8. 对话记录

路径：**对话记录**

### 查看对话

- 默认显示所有状态的会话
- 可按状态过滤：全部 / 进行中 / 已转人工 / 已关闭

### 状态说明

| 状态 | 含义 |
|------|------|
| 进行中 | AI 正在处理，或等待用户回复 |
| 已转人工 | AI 触发了转人工，等待客服接管 |
| 已关闭 | 会话已结束 |

### 查看详情

点击任意会话，可查看完整的消息时间线，包括 AI 回复、工具调用过程和客服回复。

## 9. 访客管理

路径：**访客管理**

### 搜索和筛选

- 搜索框：按姓名或 ID 搜索
- 标签下拉：按标签筛选访客

### 编辑访客信息

点击访客行，可编辑：
- **姓名**：备注显示名称
- **标签**：添加或删除标签（如"高价值"、"投诉客户"）
- **备注**：内部备注信息
- **AI 开关**：关闭后该访客的消息不走 AI，直接等待人工

## 10. 日常运营流程

### 新系统上线前

1. 上传知识库文档（退款政策、产品说明、常见问题等）
2. 添加高频 QA 条目（至少 20-30 条）
3. 修改 Agent 系统提示词，符合品牌风格
4. 添加客服账号
5. 用「聊天测试」页面测试 AI 回答质量

### 日常处理流程

1. 客服登录工作台，保持页面开启
2. 有新转人工会话时，左侧列表实时提示
3. 点击接管，查看上下文，回复用户
4. 处理完成后关闭会话

### 优化 AI 回答质量

- 发现 AI 回答不准确 → 在 QA 知识库添加对应条目
- 发现 AI 风格不对 → 修改 Agent 系统提示词
- 发现某类问题 AI 处理不好 → 创建对应工作流

### 定期维护

- 每周查看概览页数据，关注转人工率变化
- 转人工率高 → 补充 QA 条目或优化提示词
- 定期更新知识库文档（政策变更时及时更新）
